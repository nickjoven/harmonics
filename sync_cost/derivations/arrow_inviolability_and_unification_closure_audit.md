## Finding 1 — The 1D arrow of time is a structural identity

### Statement

The 1D arrow of time (forward-only direction along a single
parameter) is **structurally inviolable in the framework's
apparatus**, composed from six independent sources. No single
source forces the inviolability alone; their composition does.

### The six composing sources

**Source A — Dissipation's algebraic universality** (parent
stratification audit). Dissipation is the only conservation
invariant that crosses every regime transition (Planck,
Standard, Hubble; K=1/K<1; pocket/medium) without degradation.
Its rank-1 Fréchet algebraic structure has no backward channel:
the substrate's dynamics gradient-flow in one direction.

**Source B — Time as the parameter dissipation runs along**.
Time is the parameter t in φ(x, y, t); it is *not* part of the
spatial arena K². The substrate's self-sustenance is a time-
evolution test (Stribeck N=3 threshold); the SL(2,ℝ) coupling
loop closes IN time. Time is structurally a single parameter
at any frame; dissipation runs along it; the parameter's
direction is forced by dissipation, not by independent
postulate.

**Source C — Substrate primitives don't admit reversibility**.
Integer arithmetic is closed under addition but irreversible
under reduction (truncation, mod operation, GCD); the mediant
operation is constructive but not invertible (no canonical
"inverse mediant"); Mihailescu's (q_2, q_3) = (2, 3) is
asymmetric in the algebraic identity (q_2² − 1 = q_3 ≠ q_3² − 1
= q_2³). The primitives themselves carry directional bias
absent observer-symmetric inversion.

**Source D — Z/2 toggle is symmetric but requires time**. Z/2
itself is reversible (0 ↔ 1), but operating Z/2 requires time,
and time runs forward by Source A. So the substrate's only
symmetric primitive is still embedded in directional time,
preserving the arrow.

**Source E — Halt/shock structuring** (PR #224). Every halt/
shock transition follows conservation + topology + phase +
symmetry + bifurcation universality. Time-reversed transitions
would have to satisfy the same constraints in reverse, but
dissipation universality (Source A) forbids backward-
dissipation, which most halt/shock transitions require to run
backward. The "structured, not chaotic" claim of PR #224 is a
positive forward-direction statement; the negative form
"backward-direction is unstructured" follows by composition.

**Source F — CPT theorem alignment + modern QM mainstream**.
T-violation observed in weak interactions (CP violation; CPT
exact → T-violation implied). Nature explicitly picks a forward
direction. Mainstream QM (decoherence, GRW, MWI, Bohmian, etc.)
excludes backward-in-time at operational level. The framework
inherits this exclusion as *derived from algebraic dissipation*
rather than postulated.

### The composite reading

The 1D arrow is inviolable because backward-in-time apparatus
would have to violate ALL SIX sources simultaneously:

- Backward dissipation (violates A)
- Time as bidirectional parameter (violates B)
- Reversible primitives (violates C)
- Z/2 toggle decoupled from time (violates D)
- Backward halt/shock transitions (violates E)
- CPT-violating apparatus + non-mainstream QM (violates F)

No consistent reading admits such an apparatus. The 1D arrow is
forced.

### MODAL/GENERATIVE diagnostic

- **Modal**: can the framework state the 1D arrow is
  structurally inviolable? **Yes** — each of the six sources
  is canonical apparatus or sealed prior finding.
- **Generative**: does the framework FORCE the arrow's
  inviolability? **Yes** — the composition of six independent
  sources gives no consistent reading where the arrow could be
  violated; any single backward-direction apparatus would
  require violating multiple structural commitments
  simultaneously.

### Finding 1 verdict: MODAL ✓ / GENERATIVE ✓

The 1D arrow of time is a structural identity in the
framework's apparatus, composed from six independent sources.
The same epistemic shape as PR #221's K² emergence ≡ Planck
self-sustenance identity: multiple independent forcings
converging on one structural commitment.

### Falsifiers

- **F-arrow-1**: empirical demonstration of backward-in-time
  causation at any scale would falsify Source A's dissipation
  universality
- **F-arrow-2**: substrate-level reversible operation
  demonstrated would falsify Source C's primitive directionality
- **F-arrow-3**: CPT violation observed (not just CP, but the
  combined CPT operation) would falsify Source F
- **F-arrow-4**: detailed-balance-violating dynamics in a
  closed framework-admissible system would falsify Source E
  (structured-not-chaotic claim)

Each falsifier targets a single source; the arrow's
inviolability survives any single falsifier provided the others
hold, but full falsification across multiple sources would
require systematic restructuring of the framework's apparatus.

## Finding 2 — Closing Gap 5 (matter-antimatter asymmetry)

### Gap statement (from PR #226)

The framework admits asymmetric survival (kink+antikink
cancellation with topological-protected residue) but doesn't
predict the specific ratio ~10⁻¹⁰ observed empirically.

### Closure shape: structural-existence + observational-
magnitude (analog of anchor structure)

The gap closes by recognizing the same structural pattern as
PR #223's anchor analysis:

- **Structural-existence component** (forced by framework):
  asymmetric survival under topological protection is forced
  by Q mod 2 invariance + dissipation universal + K²
  antiperiodic identification + topological halt category.
  *Without* asymmetric survival, our pocket wouldn't exist;
  the framework forces *that* asymmetric survival happens.
- **Observational-magnitude component** (anchored input): the
  specific ratio ~10⁻¹⁰ is observational input, similar to
  how H_0 and v_EW values are observational while the
  two-anchor minimum is structural per PR #223.

The asymmetry magnitude is structurally a *matter-sector
observational input* — not a fourth fundamental anchor (which
would conflict with PR #223's two-anchor minimum), but a
property of the matter sector that requires its own observed
value while emerging from the v_EW anchor's matter-sector
structure.

### Why this is a closure, not a continuation of openness

The framework's apparatus has *no derivation channel* that
would produce a specific asymmetry magnitude from substrate
primitives alone. The Sakharov conditions (baryon-number
violation, CP violation, out-of-equilibrium dynamics) all have
framework analogs (non-local Q mod 2 processes, K²
antiperiodic CP-like structure, dissipation universality), but
their *quantitative composition* into a specific ratio
requires observational input.

This is structurally identical to anchor-not-derived status: the
framework forces the *form* of the answer (some asymmetry
exists; structurally must be small) but the *value* (10⁻¹⁰)
is observational.

### Gap 5 closure verdict: STRUCTURAL CLOSURE (existence-forced + magnitude-anchored)

The gap is closed by recognizing the structural pattern, not
by deriving 10⁻¹⁰ from substrate primitives. The closure has
the same shape as PR #223's anchor-not-derived status: the
framework forces what it can; what it can't, it acknowledges
as observational input.

`continuum_limits.md`'s disposition note (PR #215). Whether

- Other pockets are *admitted* by substrate dynamics
- They are *not enumerated* by framework apparatus
- Observation from inside our pocket *cannot access* their
  contributions directly

  contributions mix or remain localized

This is structurally identical to PR #223's "other admitted
configurations" indeterminacy class:

- **Structural admittance** (forced): other pockets exist per
  the K=1 medium hosting structure
- **Enumeration indeterminacy** (forced): the framework's
  apparatus doesn't enumerate; observation can't access; thus
  count and contribution mixing remain indeterminate from
  inside

The gap is **structurally closed** as a recognized
indeterminacy class, not as an unresolved derivation gap. The
framework's apparatus correctly handles this case: it admits
the existence, acknowledges the inaccessibility, and doesn't
fabricate enumerations or mixing claims.

### Why this is a closure

A genuine derivation gap would have the framework's apparatus
admitting a question the apparatus could answer if more work
were done. Gap 6 is different: the question is one the
apparatus *structurally cannot answer* from inside our pocket,
and the framework recognizes this as a feature.

The closure: Gap 6 is properly classified as an
**inaccessibility class**, parallel to "sub-Planck physics
beyond the floor" (PR #221) and "value of anchors outside our
pocket" (PR #223). These are NOT open gaps in the
derivation-pending sense; they are structurally identified

### Gap 6 closure verdict: STRUCTURAL CLOSURE (indeterminacy as feature)

The gap is closed by recognizing its membership in the
inaccessibility class. The unification audit (PR #226) can
cite it as "structurally indeterminate by construction"

## Finding 4 — Closing Gap 7 (dominant mechanical process)

### Gap statement (from PR #226)

Among the five mechanical processes producing the medium's
apparent simplicity (cancellation + equilibration + decoherence
+ topological-filtering + dissipation history), which is
dominant?

### Closure shape: vocabulary-variant recognition (the question was ill-posed)

The five processes are not competing alternatives but
**vocabularies for the same mechanism**: substrate dissipation
manifesting at coherence boundaries at different layers / from
different observer perspectives.

| "Process" vocabulary | What it actually names |
|---|---|
| Cancellation | Dissipation operating on antipodal pairs (K² antiperiodic) |
| Equilibration | Dissipation reaching the ground state (rank-1 Fréchet attractor) |
| Decoherence | Dissipation losing phase coherence (interference structure decay) |
| Topological-filtering | Dissipation operating on protected vs. unprotected configurations |
| Dissipation history | Integrated temporal effect of dissipation |

All five are descriptions of dissipation acting at coherence
boundaries. They differ in vocabulary, not in mechanism. The
dominance question dissolves because there's no dominance
hierarchy to identify.

### Why this is a closure

Asking "which process dominates" presupposes distinct competing
mechanisms — which the framework's apparatus doesn't admit.
Each vocabulary highlights a different aspect of dissipation
(antipodal pair structure for cancellation; ground state for
equilibration; phase coherence for decoherence; protection
filter for topological-filtering; temporal integration for
history), but they're the same mechanism viewed from different
observer perspectives.

The dissolution: Gap 7 is closed not by identifying a dominant
process but by **recognizing the question was status-confused**
— vocabulary variants of one mechanism treated as competing
alternatives.

### Observation-relativity of the vocabulary choice

Different observer perspectives privilege different
vocabularies:

- **From inside our pocket**: "topological-filtering" is the
  most operationally visible — we see what survived
- **From outside (medium perspective)**: "cancellation" would
  be most visible — we'd see what cancelled
- **From substrate-dynamics perspective**: "dissipation
  history" is the most accurate — the medium's state IS the
  dissipation integral

All are correct; none dominates absolutely. The closure
recognizes this observation-relativity as a framework feature
(consistent with PR #220's geodesic discussion + surface
uniqueness + Q mod 2 absorbs orientation ambiguity).

### Gap 7 closure verdict: ILL-POSED RECOGNITION (vocabulary variants of one mechanism)

The gap is closed by reframing: there's no dominant mechanism
to identify because the five process names are vocabulary
variants of substrate dissipation. PR #226's Sub-claim C
(medium-as-cancellation-residue) stands at MODAL ✓ / GENERATIVE
✓ with this clarification.
