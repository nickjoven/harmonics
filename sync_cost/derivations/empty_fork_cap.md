## The decorated-fork object

Every framework fork node is a triple **F = (B, ι, δ)**:

- **B** — the two-branch set {+, −} (kink/antikink; Loop1/Loop2;
  ±√μ; the two bicone sheets; mediant parent-pair).
- **ι** — the branch-swap involution, `ι² = id` (the abstract
  half-twist; the Z₂).
- **δ** — the **orienting datum**: the single structural feature
  that breaks ι by selecting/weighting a branch. When present, δ
  *is* the fork's dynamics.

## ∅, formally

> **∅ = (B, ι, 0).** The branch set at ∅ is a **Z₂-torsor with no
> basepoint**. Every decorated fork is *the same torsor with a
> basepoint chosen by δ*. ∅ = any fork with the basepoint
> forgotten.

This is "one less degree of freedom / dimension / structural
feature", all the *same* statement:

- **one less DOF**: fork DOF = 2 (branches) + 1 (δ); ∅ = 2 + 0.
- **one less dimension**: in fork-moduli space δ is a ≥1-dim
  modulus; ∅ is the **codimension-1 locus δ = 0** — the wall every
  fork's apex lies on. Not a different object; the bottom stratum.
- **one less structural feature**: the absent feature is the
  basepoint — exactly the one that, present, supplies
  feedback/destructive-interface/epoch dynamics. Its absence is
  *why* ∅ is the unique undecorated fork.

**Selector lemma.** A selector is a point of B. An ι-respecting
selection needs an ι-fixed point of B; ι is the free swap and has
none. So **at δ = 0 no symmetric selector exists** — the first
distinction is a *free section of a torsor*, not a function of
anything in the structure. "The first distinction is unforced" is
a one-line consequence, not a slogan.

**Forget map.** `U : (B, ι, δ) ↦ (B, ι, 0)` sends *every*
framework fork to the same ∅. ∅ is not one node among the others
— it is their **common image under orientation-forgetting**: the
universal apex the D-crossing, saddle-node, half-twist, mediant,
bicone, epoch ladder all degenerate to. One ∅, reached from
anywhere by forgetting the basepoint. (Concretely: the framework's
*committed* "first mediant" is `K = 1/2` from the boundary pair
`(0/1, 1/1)` — `qd_origins.md`; ∅ is that node with its
tongue-width order forgotten, i.e. with *no* "simplest" child
selected.)

## The four-faces identity (the cap)

    R1 provable
       ⟺  a deductive selector exists at the root
       ⟺  the root torsor has a canonical basepoint
       ⟺  δ_root ≠ 0
       ⟺  the root is NOT ∅
       ⟺  the framework's ∅-doctrine is false.

Contrapositive: **∅ true ⟹ R1 unprovable.** Unprovability is
*entailed by* the framework's ∅, not conceded against it. A proof
of R1 would be a **falsification signal** (it would mean the first
distinction had a prior — i.e. ∅ was not nothing), not a triumph.

## Bright line (formal, load-bearing — do not over-read)

The torsor supplies a *reason no canonical basepoint exists*; it
never supplies a basepoint. ∅ explains why **neither** P0
(coupled-oscillator ontology) **nor** Q0 (continuum-field
ontology) can be deductively forced; it does **not** pick P0.
Discrete-fundamental is favored *only* by the downstream abductive
arrows (`#TICK` eliminates competitor #2 by construction; `#FLOW`
by absent-fingerprint + parsimony) — abductive sections of the
torsor, never a deductive basepoint. **Self-consistency, not
proof.**

What this changes vs. the prior standing: "favored, not proven —
parsimony ceiling" becomes "favored, not proven — and the
not-proven half is **∅-entailed**, predicted by the framework's
own cosmogenesis, not a defect." Strictly stronger and strictly
more honest; not a step toward a proof (there can be none).
