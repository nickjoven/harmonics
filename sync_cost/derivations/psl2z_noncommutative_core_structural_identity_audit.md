- `S = [[0, −1], [1, 0]]` of order 2 (`S² = I`)

3. **The free-product structure of PSL(2,ℤ)** is established

## Canonical depth: hyperbolic length

### Statement

The framework's canonical depth measure on Γ(2) (and by
extension on framework's modular content) is hyperbolic length:

    ℓ(γ) = 2 · arccosh(|tr(γ)|/2)

for an element γ ∈ Γ(2). This is the length of the closed
geodesic on `H / Γ(2)` corresponding to γ's conjugacy class.

### Why not word length

Word length counts the number of generators in a reduced word
for γ. This is a natural combinatorial measure but:

- Different elements with same word length can have very
  different hyperbolic lengths
- Example from lunar-theory: `ab → 3.525`, `aB → 0` at same
  word length (where lowercase and uppercase indicate generator
  and its inverse)
- Word length collapses noncommutative distinctions that
  hyperbolic length preserves

### Connection to framework's substrate depth

The framework's substrate depth has been treated implicitly:

- PR #221's Planck floor: depth at the N=3 self-sustenance
  threshold
- PR #228's 1D arrow: depth along time
- PR #237's H_0 tension: depth at K=1/K<1 critical line

These are all "1D" depth measures (along single parameters).
The noncommutative depth on F₂ is the **rank-2 generalization**:
two generators, hyperbolic-metric depth, captures actual
structural distance rather than combinatorial complexity.

### Methodology suggestion

Future framework depth analyses should use:

- Hyperbolic length on Γ(2) (or generally on framework's modular
  surface H/Γ) as canonical depth
- Word length only as combinatorial-counting heuristic, not
  predictive measure
- The rank-2 analogue (hyperbolic length on F₂) is the framework
  apparatus's canonical depth measure for noncommutative content
