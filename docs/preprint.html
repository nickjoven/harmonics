The four deliverables

1. Structural lemmas (structural_lemmas.md)

~10 pages. Nine load-bearing structural lemmas catalogued for citation. Each lemma is independently statable with proof source, Z1-Z3 status, and substrate / anchor classification.

  1. w+ closure (headline): $Z_6$ + $\Gamma_0(6)$ cusp 1/2 + $(q-1)/q$ ground state $\Rightarrow$ $w_+ = 13/14$, partition $\Omega_b : \Omega_{DM} : \Omega_\Lambda = 13 : 70 : 181$.
  2. Sign-rep no-EM: antisym Klein eigenmode has Klein-monodromy $-1$, no EM coupling, locks at $w_- = 1$; forces $(\alpha, \beta) = (0, 1)$.
  3. Two-anchor minimum (D.3): $K = 1 \leftrightarrow K < 1$ non-smooth separation forces $(H_0, v_{EW})$ as minimum dimensional input.
  4. Cosmic partition (single-w): $Z_6$ mode counting + Klein-singlet + coprime-to-6 + inner/boundary gives $13 : 5 : 1 / 19$.
  5. $q_3$-quantity closed form: $M_i = (|F_7| - N_i) / q_2$ forces matter sector $M_{DM} = 7$ from existing partition.
  6. Hecke cusp $\leftrightarrow$ $Z_p$ rep: substrate $\Gamma_0(6)$ preservation maps $Z_p$ reps to $X_0(6)$ cusps; $\psi_+(1, 5)$ trivial $Z_2$ → cusp 1/2.
  7. Born rule exponent $= 2$ from saddle-node parabola universality.
  8. Spatial dimension $= q_3 = 3$: substrate's $Z_3$ sector forces three independent extension directions.
  9. Pigeonhole calibration (Region C): at $\alpha = 0.05$, multi-candidate framework-integer ansatz is statistically consistent with permutation null.

Composition graph: lemmas 4 → 5 → 6 + 2 → 1 produces the cosmic partition two-component closure with zero free parameters at the closure level. Lemmas 3, 7, 8 are independent structural results; lemma 9 is methodological.

2. Canonical glossary (canonical_glossary.md)

~10 pages. Translation table between the framework's internal vocabulary and standard physics / mathematics terminology. Approximately 70 framework terms across 10 thematic sections, each with operational definition and source-doc cross-reference. Intended to be readable end-to-end in 30 minutes by a working physicist with no prior framework exposure.

Sections: primitives; substrate structure; mode representation theory; coupling regimes (K-zoo, MOND threshold); modular and number-theoretic structure (Stern-Brocot, $PSL(2, \mathbb{Z})$, $\Gamma_0(N)$, $X_0(N)$ cusps); cosmological observables; particle observables; methodology; cross-domain unifying terms; imported framings explicitly NOT translated (hierarchy problem, naturalness, $K_c$, cutoff — with reasons each doesn't apply).

3. Phenomenology cross-reference (phenomenology_cross_reference.md)

~12 pages. Observation vs framework prediction comparison for ~40 well-documented phenomena across 11 thematic sections, with explicit Z1-Z3 status, closure class, and substrate-side / anchor-side classification.

Headline: ~15 Survives entries (zero free parameters at closure level), 1 Instance 7 acceptance ($A_s$), ~3-5 Floor / pigeonhole, large Class 2 population for flavor / mass / CKM matches, explicit out-of-class for anchor-dependent absolutes. Includes a "standard physics open problems addressed" section mapping the cosmological constant, hierarchy, GR-QM unification, MOND, EPR, etc. to framework status.

4. Derivation atlas (derivation_atlas.md)

~50 pages, 1943 lines. Single linear walkthrough of the framework's derivation chain, from the four primitives to approximately 15 substrate-side Class 5 / Survives predictions, in 11 parts plus prelude / postlude.

Parts: I. Four primitives (irreducibility + sufficiency); II. Derived objects (circle, $\mathbb{Q}$, continuum, circle map); III. Dynamical content (Arnold tongues, devil's staircase, K-regimes); IV. Substrate structure ($Z_6$ mode lattice + Klein-antipodal $Z_2$ + color $Z_3$); V. Geometric / topological derivations (spatial dim, Lorentz, Born rule); VI. Coupling regimes ($K$-zoo, MOND threshold, substrate discreteness); VII. Cosmological derivations (partition, $R$, $\Lambda$, two-component closure, $n_s$, $A_s$); VIII. Modular structure and $\Gamma_0(6)$ closure (Hecke cusps, L1, $w_+ = 13/14$); IX. Particle physics derivations (gauge group, anomalies, strong CP, quark factors); X. Methodological framework (Z1-Z3, anchor-side, modes, pigeonhole, vocabulary pattern); XI. Synthesis and non-claims.

Verbose by design: each derivation step explicitly stated, mathematical content separated from physical interpretation. The document does not lend itself to skimming.
