Mastery graph — concepts as a navigable network

Each node is one concept, described in plain language. Each edge runs from a prerequisite concept to a concept that builds on it. Traversing every connected node, in roughly the order suggested by the prerequisite arrows, is intended to leave a reader in possession of the framework's core dynamics.

Nodes are coloured by cluster (see the row of cluster labels above the graph; click a cluster label to hide or show that cluster). Clicking a node opens its description in this pane, with links to its prerequisites and downstream concepts.

The descriptions are written without recourse to the framework's eponymous vocabulary. For the literature names, see the phenomenon glossary; for the canonical scorecard, see the claim chain.
