what's on screen

Two phase oscillators on the same unit circle. Each one has its own natural angular velocity ($\omega_1$, $\omega_2$). The coupling $K$ pulls them toward each other:

$$\frac{d\varphi_1}{dt} = \omega_1 + K\sin(\varphi_2 - \varphi_1), \qquad \frac{d\varphi_2}{dt} = \omega_2 - K\sin(\varphi_2 - \varphi_1)$$

The phase difference $\Delta\varphi = \varphi_2 - \varphi_1$ obeys

$$\frac{d\Delta\varphi}{dt} = (\omega_2 - \omega_1) - 2K\sin(\Delta\varphi).$$

Locking condition: $|\omega_2 - \omega_1| \le 2K$. When the inequality is met, $\Delta\varphi$ stops changing — the lower chart goes flat — and both oscillators rotate at the same instantaneous frequency $(\omega_1 + \omega_2)/2$.

what the chart says, in words

If you can't see the chart, the state badge above tells you whether the system is locked or drifting along with the live numbers. Drifting means $\Delta\varphi$ grows or oscillates without settling; locked means $\Delta\varphi$ converges to a fixed offset and stays there.

where this lives in the framework

This is the simplest case of the substrate's mode-locking dynamics. Stern-Brocot enumeration, Arnold tongue widths $\sim (K/2)^q$, and the devil's staircase all sit on top of this single mechanism — what changes in later stages is which $(p, q)$ ratios are accessible, not the underlying lock-or-drift behavior.
