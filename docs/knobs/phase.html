what's on screen

One phase variable $\varphi(t)$ rotating around a circle. The knob sets its angular velocity:

$$\frac{d\varphi}{dt} = \omega$$

The dot's position is $(\cos\varphi, \sin\varphi)$. Doubling ω doubles the rotation rate. There is nothing else here — that's the point. The substrate is built out of variables exactly like this one.
