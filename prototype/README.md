# Metronome wall — coupled oscillators on S¹

Interactive demonstration of synchronization-cost framework Tiers 0–3, in a single browser page.

## What this shows

Move the K slider. Watch:

- A grid of N oscillators, each at a slightly different bare frequency, ticking on individual phase circles.
- An order parameter |r| in the header, growing as the cloud locks.
- A live W(Ω) plot building into the devil's staircase as you turn up coupling.

The five claims the wall is meant to make visible:

1. Coupled oscillators lock to **rational** frequency ratios.
2. The locking ratios are exactly the **Stern-Brocot tree** at depth determined by K.
3. Which tongues open at which K **is** the devil's staircase.
4. φ⁻¹ is the **last** point to lock.
5. K_c = 2/π is the visible threshold for the first cluster.

## How to run

This is a static page. From the prototype directory:

```
cd /home/user/harmonics/prototype
python3 -m http.server 8080
# then visit http://localhost:8080/
```

ES module imports require a real HTTP server; opening `index.html` directly via `file://` will fail.

## Validation

`test/tongue_widths.html` runs `CircleMapEngine.tongueWidth` and compares cell-by-cell to `reference_widths.json`. The reference is produced by:

```
python3 sync_cost/derivations/tongue_widths_exact.py \
    --dump-json prototype/test/reference_widths.json
```

Pass criterion (per cell):

- If reference > 0.01: |measured − reference| / reference ≤ 10%.
- If 0 < reference ≤ 0.01: |measured − reference| ≤ 0.001.
- If reference = 0 (below the script's resolution): measured ≤ 0.01 → trivial pass.

## Known limits

- The Python reference resolves only the q = 2 tongues at default transient counts. Higher-q tongues require boosted transients (10⁵+) or a different measurement strategy. The validation harness inherits this and treats those cells as trivial-pass.
- Audio voice cap is 32; with N = 400 you will hear a downsampled subset.
- Frame rate target is 60 fps at N = 100, ~30 fps at N = 400 on a typical laptop.

## Pedagogical exercises

Three suggested in-class exercises, each ~5 minutes:

1. **Find K_c.** Adjust K from 0 until the first stable cluster forms. Read the value. Compare to 2/π ≈ 0.637.
2. **Find the 1/3 plateau.** At K = 0.7, identify the cluster of tiles ticking at exactly 1/3 the dominant rate. Hover to verify.
3. **Where is φ⁻¹?** At K = 0.99, find the last unlocked tile. Verify its bare frequency is closest to 0.618 ≈ 1/φ. Conjecture why.
